不在工作目录 Mini_Nodepad（那是 Java 后端）。别找错地方。**

### 核心发现：本项目没有 tailwind.config.js
用 Tailwind **v4**（`@tailwindcss/vite`），CSS-first 配置，
`tailwind.config.js` 的等价物 = `src/styles/index.css` 里的 `@theme inline` 块。
**v4 下不要新建 JS 配置文件。**

### 落地的三层架构（关键设计）
```
Layer 0  src/styles/primitives.css  【新增】原语层 --x-*
         <html data-style × data-theme × data-accent> 交叉解析
Layer 1  src/styles/tokens.css      【改造】语义层，变量名一个没改，值改成 var(--x-*)
Layer 2  src/styles/index.css       @theme inline → .bg-card / .rounded-card
```
组件永远写 `bg-card` / `rounded-card`，切风格只改底层 --x-* → **全站旧组件无痛换肤**。

### 风格差异的实现技巧（复用价值高）
- `--x-lift`：Swiss/Editorial 设 0px，`.lift-hover:hover{transform:translateY(var(--x-lift))}`

## 阶段 E：字体 × 图标搭配层（用户拍板"两者都要"）

### 关键技术发现（可复用）
1. **Lucide 渲染的 svg 自带 `.lucide` 类**，且 `stroke-width` / `stroke-linecap` /
   `stroke-linejoin` 是 **SVG 表现属性** —— 优先级低于任何 CSS 规则。
   → 线宽可以**零组件改动**全局接管。已把全站 96 处 `:stroke-width="N"` 全部删掉
   （37 个文件），它们是死参数。
2. **lucide 的 stroke-width 是 24 viewBox 单位**：13px 图标上写 1 ≈ 实际 0.54px，
   非 Retina 屏会淡到看不见。Editorial 规范写的 1 实测不可用，取 1.25。
3. Tailwind v4 的 translate 工具类用 **`translate` 属性**（不是 transform），
   所以 `.lucide { transform: scale() }` 不会和 `-translate-y-1/2` 打架。
   但 `animate-spin` 的 keyframes 用 transform:rotate，会覆盖 scale（可接受，
   所以加载指示统一加 `.icon-fixed`）。

### 新增原语（primitives.css）
`--x-icon-stroke / -scale / -cap / -join / -opacity` + `--x-show-icon / --x-show-glyph`
+ 三套字体栈 `--x-stack-apple / -swiss / -serif`（全部本地字体，不依赖 CDN）。

| | Apple | Swiss | Editorial |
| --- | --- | --- | --- |
| stroke | 1.75 | 2.5 | 1.25 |
| scale | 1 | 0.88 | 1.04 |
| cap/join | round/round | **butt/miter** | round/round |
| font | SF Pro 栈 | Helvetica 栈 | 衬线栈 |

### 新增组件类（index.css）
- `.icon-apple` → `display: var(--x-show-icon)`：只在 Apple 显形的装饰图标
- `.glyph-plain` → `display: var(--x-show-glyph)`：Swiss/Editorial 的排版符号
- `.icon-fixed` → 豁免缩放（加载指示、Logo）
风格判断仍然 100% 收敛在原语层，模板里不写 v-if。

## 深夜续做：「点书库 / 管理来源整页白屏」根因定位与修复（本日最大战果）

### 真凶：路由 Transition 的 `mode="out-in"`
`src/App.vue` 里 `<RouterView v-slot="{ Component }">` + `<Transition name="route" mode="out-in">`
+ `<component :is="Component" />` 这个组合，在 **Vue 3.5 + vue-router 5** 下，
离开过渡结束后**不会再把新组件插回来**：插槽值变成 `undefined`，渲染成一个注释占位符并**永久停住**。
表现 = 点「书库」/「管理来源」整页纯白、**控制台零报错**、刷新才好（有时不好）。

**修复**：去掉 `mode="out-in"`（保留淡入淡出）；因为失去 out-in 后新旧两页会同时在 DOM 里，
用 `.route-leave-active { position: absolute; inset-inline: 0; top: 0 }` 让离开态脱离文档流；
再加 `v-else` 兜底（宁可显示"正在加载页面…"也不要静默白屏）。

二分实测（`_cdp_probe.mjs`，7 步导航）：
| 变体 | 结果 |
| 朴素 `<RouterView />` | 正常 |
| Transition 无 mode | 正常 |
| Transition `mode="out-in"` | **白屏** |
| out-in + `:key="route.path"` + `v-if="Component"` | 仍白屏 → **`:key` 救不了** |

### 定位手段（可复用）：自建 CDP 探针 `_cdp_probe.mjs`
这台机器**没有 `agent-browser` CLI**（PATH 里找不到，全局也没装），
但 **Chrome 在 `C:\Program Files\Google\Chrome\Application\chrome.exe`**，
且 **Node 22 自带原生 `WebSocket`** → 直接 headless Chrome + CDP，零依赖：
- spawn `chrome --headless=new --remote-debugging-port=9222 --no-proxy-server`
- `fetch http://127.0.0.1:9222/json/list` 拿 `webSocketDebuggerUrl` → `new WebSocket(url)`
- `Page.enable` / `Runtime.enable` / `Log.enable` / `Network.enable`
- 注入 `localStorage.setItem('mnl.token', ...)` 绕过登录（测试账号 **demo / demo12345**）
- `Runtime.evaluate` 做 DOM 体检、`Page.captureScreenshot` 截图
以后凡是"要真浏览器才能复现"的问题，都走这条路。

### 关键取证心得
- **白屏 + 控制台干净 = 不是 JS 报错，去看 DOM 到底有没有元素**。
  当时 `router.currentRoute` 完全正常（`matched.length=1`、`components.default` 就是 `BookshelfView`），
  但 `#app.childElementCount === 0`、`innerText === ''` —— 一眼就指向"插槽渲染空了"。

### ① Bug 根因（像素级取证定位）
`.mm-node` 写了 `border-bottom: var(--x-mm-node-underline, none)`，而 base/Apple/Swiss
把该变量定义为 none —— Editorial 专用的"仅底线"简写**把所有风格的下边框干掉了**。
Swiss 下相邻叶节点视觉上连成开口的"空盒"。
取证方法：headless Chrome 截图 → `_png_lines.py` 的手写 PNG 解码逐列扫描 →
按钮 42px 高，底边框应在 y≈143，但 62~173 全空，y=174 那条是**下一个叶节点的顶边**。
（DOM 测量全正常、elementsFromPoint 干净 —— 纯 CSS 视觉 bug，只能靠像素取证。）

修法：底边改颜色长手 `border-bottom-color: var(--x-mm-node-underline-color, ...)`；
Editorial"仅底线"只覆写颜色。

### ② 叶节点加深（`--x-mm-leaf-*` + `.mm-node.is-leaf`）

### ③ Editorial 根节点标志

### ⚠️ 新坑（本轮第 2 个 CSS 变量坑，已写进 MEMORY.md 第 5/6 条）
- `border-bottom: var(--x, none)` 简写开关会误杀其余风格的边框 → 一边可选时只用颜色长手。
- **CSS 自定义属性沿继承链回落**：`[data-style=editorial]` 没定义 `--x-mm-leaf-bg` 时
  **继承 :root 的值**，var() fallback 只在整条继承链都没定义时才生效
  → Editorial 叶节点凭空长出灰底。规矩：每个 [data-style] 段显式写全自己需要的值。
